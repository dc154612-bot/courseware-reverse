用法：

不要填写真实学生的姓名、成绩等信息。

## 输出规则（必须遵守）

1. 除了“我的课”里要你列在代码块前面的内容，只输出一个 ```javascript 代码块，里面是完整的学科内容代码。不要写 HTML、CSS、<script> 标签、import，不要创建 renderer、scene、camera、灯光，不要调用 start()。
2. 代码里必须定义：`SCENE`、`buildSubject()`、`fresh()`、`render()`、`ACTIONS`。可以另外定义 `onPick(info)`（点选物体时调用）和 `currentView()`（“复位视角”按钮转到哪个视角）。
3. 只使用下面“积木清单”里的函数和 THREE 的基础几何体、材质。不要用 OrbitControls、GLTFLoader、后期处理、外部图片、外部模型文件，也不要用 fetch。
4. 代码要完整，不要写“此处省略”。太长时减少装饰物，不要截断。

## 坐标约定

- x 向右，y 向上，z 朝向镜头。地面大约在 y = 0。
- 整个场景放在 SCENE.size 的范围内，例如 [12, 5] 表示宽约 12、高约 5。
- 常用尺寸：一棵树高约 1，一栋楼高 0.5～1.5，云在 y = 3 左右。

## 怎样让画面好看（重要）

- 先用 `ground()` 做一块沙盘底座：四边自动切开，露出分层。
- 主体 3～6 个，每个用 3 个以上积木拼起来。例如房子 = 墙体 box + 屋顶 cone + 门 box；细胞 = 外膜 lathe + 细胞核 ball + 几个细胞器。
- 成批的东西（树、草、房子、植株、分子）要几十个，用 `trees()` 或 `scatter()` 配合 `spots()`，大小、颜色、朝向都有差异。
- 颜色用自然、低饱和的颜色。强调色（SCENE.theme.hl）只给要学生注意的对象。
- 要学生看的对象：加 `tag()` 标注，在 SCENE.views 里给它一个视角，出题时用 `focus()` 转过去。
- 只让表达知识的东西动：水流、电流、生长、转动。不要做装饰性动画。
- 文字一律用 `label()` 或 `tag()`，不要做 3D 文字。

## 教学规则

- 先预测再验证：学生先选或先说，再看结果。
- 答错时，在场景里把学生选的那一项也标出来（`.set('alt')`），和正确的一项对比。反馈要说清错在哪、下一步看哪里，不能只写“错误”。
- 所有面板和场景的变化都写在 `render()` 里：先改 state，再调用 render()。
- 用 `ui.rec()` 记录学生每一步的答案，最后可以一键复制当作业。

## 积木清单

形状（y 是底面高度；ball 的 y 是球心；o 里可以写 x, y, z, rx, ry, rz, s, parent, opacity, glow, flat）：
- `box(宽, 高, 深, 颜色, o)`、`cyl(顶半径, 底半径, 高, 颜色, o)`、`cone(半径, 高, 颜色, o)`、`ball(半径, 颜色, o)`
- `lathe([[半径, 高度], ...], 颜色, o)`：旋转体，做瓶子、烧杯、花盆、细胞、果实
- `tube([[x,y,z], ...], 半径, 颜色, o)`：弯管，做导线、血管、根、河道
- `group(o)`：把几个形状组成一个整体，形状的 o 里写 `parent: 这个group`

地形和成批的东西：
- `ground({ w, d, height:(x,z)=>y, color:(x,y,z)=>'#颜色'或null, water:{ y, color }, layers:[{ depth, color, name }], base })`：沙盘底座；layers 是剖面分层（depth 是离地表的深度，最后一层写 99）；`layers:false` 不切剖面
- `groundY(x, z)`：地面在这一点的高度
- `spots(n, x0, x1, z0, z1, avoid)`：随机撒 n 个点，`avoid(x,z)` 返回 true 的地方跳过
- `trees([{ x, z, s, kind:'round'|'pine' }])`：一片树
- `scatter(几何体, 颜色或'vary', [{ x, z, y, s, ry, color }])`：成批摆放同一种形状，y 不写自动贴地
- `cloud(x, y, z, 大小)`、`rain(x, z, 半径, 顶高)`

流动和标注：
- `arrow([[x,y,z], ...], { tag:'A', name, r, color })`：带流动光点的箭头，表示物质、能量、水、电流的去向。返回对象有 `.set('hl'|'alt'|'ok'|'dim'|'')` 和 `.speed(倍数)`
- `label(文字, [x,y,z], 'lbl'|'lbl water'|'lbl light')`、`tag(文字, [x,y,z])`：返回对象有 `.set(状态)` 和 `.text(新文字)`
- `pickable(物体, { title, text })`：点中物体时调用 `onPick(info)`
- `blobShadow(x, z, 半径)`：物体脚下的柔和阴影
- `animate((dt, t) => {...})`：每帧运行，系统开了“减少动态效果”时自动停止

面板和镜头：
- `ui.task(html)` 左侧任务面板，`ui.msg(html)` 右侧反馈，`ui.rec(html)` 记录，`ui.hint(文字)` 顶部提示
- 按钮写成 `<button data-act="choose" data-v="值">`，点击时调用 `ACTIONS.choose('值')`；滑块写成 `<input type="range" data-input="move">`，拖动时调用 `ACTIONS.move(值)`
- 可用的样式类：`opts`（两列按钮）、`opts one`（一列）、`primary`、`chosen`、`good`、`wrong`、`fb ok`、`fb bad`、`hint`、`big-num`、`row`
- `focus('视角名')`：镜头转到 SCENE.views 里的视角。视角写法：`{ az: 水平角, el: 仰角, z: 远近(1 = 全景), t: [看向的点] }`
- 可以使用的工具：`clamp`、`sm`（平滑 0～1）、`lerp`、`rnd()`（固定种子的随机数）、`nz(x,z)`（起伏噪声）、`C('#颜色')`、`V3(x,y,z)`

```javascript
// 示例：水循环读图（只演示积木怎么用）。换课时，整段替换成新的内容，结构保持不变：
// SCENE 配置 → buildSubject() 搭场景 → fresh() 初始状态 → render() 刷新面板和场景 → ACTIONS 按钮动作 → onPick() 点选

const SCENE = {
  title: '水循环',
  subtitle: '高中地理，读图识环节',
  sky: 'day',                        // day 晴天 / dawn 清晨 / overcast 阴天 / night 夜晚
  size: [12, 5],                     // 场景大致宽、高，用来算镜头距离
  theme: { main: '#0d4f86', hl: '#ff6a13' },
  cover: { tag: '高中地理', q: '一滴水离开海面，<br>要走多远才回来？', p: '先在立体沙盘上认出水循环的环节，答错时会在图上标出你选的那个。', btn: '开始读图' },
  noteQ: '怎样从图上分辨“蒸发”和“降水”？',
  source: '示例内容，仅演示骨架用法。',
  views: {                           // az 水平角、el 仰角、z 远近（1 = 全景）、t 看向的点
    overview: { az: .25, el: .45, z: 1, t: [0, .8, 0] },
    A: { az: -.3, el: .35, z: .7, t: [-3, 1.2, 0] },
    B: { az: .3, el: .35, z: .7, t: [2.5, 1.8, 0] },
    C: { az: .1, el: .6, z: .75, t: [0, .4, .5] }
  }
};

const LINKS = {
  A: { name: '蒸发', how: '起点在水面，箭头朝上。' },
  B: { name: '降水', how: '起点在云，箭头朝下。' },
  C: { name: '地表径流', how: '在地面上，顺着坡流向海洋。' }
};
let ARW = {};

function buildSubject() {
  // 西边是海，东边是山：用高度函数描述地形
  const H = (x, z) => -.35 + .9 * sm((x + 1.5) / 2) + 2.4 * Math.exp(-(((x - 4) / 1.6) ** 2)) * (.8 + .2 * Math.sin(z)) + .06 * nz(x, z);
  ground({ w: 12, d: 5, height: H, water: { y: 0, color: '#2f7fc0' } });
  label('海　洋', [-4.2, .05, 1.5], 'lbl light');
  label('山地', [4, 2.9, -1], 'lbl');
  trees(spots(80, -.5, 5.8, -2.4, 2.4, (x, z) => H(x, z) < .15 || H(x, z) > 2));
  cloud(-3.2, 3.3, -.5, 1.2); cloud(2.6, 3.6, -.3, 1.4);
  rain(2.6, -.3, .8, 3.2);
  ARW.A = arrow([[-3.5, .1, .8], [-3.4, 1.6, .5], [-3.2, 2.9, -.3]], { tag: 'A' });
  ARW.B = arrow([[2.4, 3.1, .3], [2.6, 2, .5], [2.7, .9, .6]], { tag: 'B' });
  ARW.C = arrow([[1.5, H(1.5, 1.2) + .08, 1.2], [0, H(0, 1.4) + .08, 1.4], [-1.6, .1, 1.5]], { tag: 'C' });
}

let state;
function fresh() { state = { order: ['A', 'B', 'C'], i: 0, ans: {} }; }
function currentView() { return state.order[state.i] || 'overview'; }

function render() {
  const k = state.order[state.i];
  if (k) {
    const opts = Object.values(LINKS).map(l => l.name);
    const a = state.ans[k];
    ui.task(`<h2>读图识环节 ${state.i + 1}/${state.order.length}</h2>
      <p>沙盘上橙色闪动的箭头 <b>${k}</b> 代表哪个环节？</p>
      <div class="opts one">${opts.map(o => `<button data-act="choose" data-v="${o}" ${a ? 'disabled' : ''} class="${a ? (o === LINKS[k].name ? 'good' : o === a ? 'wrong' : '') : ''}">${o}</button>`).join('')}</div>
      ${a ? '<button class="primary" data-act="next" style="width:100%">下一题</button>' : ''}`);
    if (!a) ui.msg('<p class="hint">看箭头的起点、终点和方向，再作答。</p>');
    else if (a === LINKS[k].name) ui.msg(`<div class="fb ok"><b>✓ 对，是${a}</b>${LINKS[k].how}</div>`);
    else {
      const wrongKey = Object.keys(LINKS).find(x => LINKS[x].name === a);
      ui.msg(`<div class="fb bad"><b>✗ 这是${LINKS[k].name}，不是${a}</b>${LINKS[k].how}紫色箭头是“${a}”所在的位置，比一比方向。</div>`);
      state.alt = wrongKey;
    }
  } else {
    ui.task('<h2>完成</h2><p>三个环节都读完了。拖动沙盘，自己再找一遍水从海洋出发、回到海洋的路线。</p>');
  }
  // 场景跟着题目变：被问的箭头橙色闪动，答错时选的那个变紫，其余变淡
  for (const x in ARW) ARW[x].set(!k ? '' : x === k ? (state.ans[k] ? 'ok' : 'hl') : state.ans[k] && x === state.alt ? 'alt' : 'dim');
  const done = Object.entries(state.ans);
  ui.rec(done.length ? `<table><tr><th>箭头</th><th>我的答案</th><th>正确</th></tr>${done.map(([x, a]) => `<tr><td>${x}</td><td>${a}</td><td>${a === LINKS[x].name ? '✓' : LINKS[x].name}</td></tr>`).join('')}</table>` : '');
  focus(currentView());
}

const ACTIONS = {
  choose(v) { state.ans[state.order[state.i]] = v; state.alt = null; render(); },
  next() { state.i++; state.alt = null; render(); }
};

function onPick(info) { ui.msg(`<div class="fb"><b>${info.title}</b>${info.text}</div>`); }
```

## 常见问题怎么跟 AI 说

- 拼装器提示“代码缺少……”或“语法错误”：把提示原话发给 AI，让它完整重写。
- 页面顶部出现红色提示条：把那句话发给 AI，说“请修改学科内容代码”。
- 画面太空：“主体再拼细一些，每个用 4 个以上积木；用 spots 和 scatter 多撒一些（树、草、石头）。”
- 看不清要看的东西：“给这个对象单独加一个视角，出题时 focus 过去，并把挡住它的东西挪开。”
- 只要改一处：“只改 xxx，其他代码保持不变，完整输出。”每轮只改一两处。
