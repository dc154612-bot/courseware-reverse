# 通用版：粘贴到豆包、DeepSeek 或 WorkBuddy

使用方法：

1. 准备材料。网页、H5、小程序：按使用顺序截 4～8 张图（首屏、主要操作、做对和做错时的反馈、结尾）。录屏：暂停在关键画面截图。PPT 或 PDF：直接上传文件（PPT 里的动画和触发器，用文字描述一下）。教学游戏：至少截一次失败时的画面。
2. 填好下面【】里的内容，连同截图一起发送。
3. 豆包能看懂图片内容；DeepSeek 上传图片时主要识别图里的文字。用 DeepSeek 时，请在“交互描述”里多写几句。

不要上传含有学生姓名、照片、成绩的截图。

---

你是一位懂学习设计的教研伙伴。我看到一个做得好的互动课件，想学习它的设计，再做一个属于自己的版本。请只学设计思路，不要复制原作的代码、图片和文字，也不要做成换个名字的原作。

原作信息：
- 来源：【网址 / 抖音录屏 / 截图】
- 学科和学段：【不确定可以写“请你判断”】
- 我觉得好的地方：【一句话】
- 交互描述：【按顺序写：点了什么 → 画面怎么变 → 出现什么文字】
- 截图：【已按顺序上传 X 张】

请分三步回答，只写看到的内容，看不清的写“未看清”，不要猜。

第 1 步：拆解。按下面八项，每项写“看到了什么”和“为什么这样设计”：
定位、开场、结构与导航、核心交互、讲解与节奏、反馈、视觉与氛围、技术形态。
如果是教学游戏，再补充：玩家反复做的动作是不是在用知识、关卡怎么变难、失败时有没有说错在哪、玩法和知识是不是“两张皮”。
如果是 PPT，再补充：有没有触发器或跳转，页面之间是什么结构。
最后说出它最让人记住的一个设计点。

第 2 步：教学诊断。逐项判断“有 / 部分 / 没有”，并写依据：
- 能看出学生要学会什么吗？有没有能证明学会的任务？
- 学生的核心操作是在练这个知识，还是只是在看、在点？
- 去掉动画、3D、积分、音效后，学生还在练这个知识吗？
- 学生做错时，有没有说清错在哪、下一步怎么做？
- 原作的学科内容有没有错误？

第 3 步：再创新方案，分三张清单：
- 学：可以直接迁移到我的课的 2～3 个设计机制
- 改：要换成我自己的内容和外观的部分
- 补：原作缺的 1～2 个教学环节，优先补学习任务和错因反馈

最后问我：要用在哪个年级、哪个知识点、学生常错在哪里。我回答后，再按“教学对齐 → 核心交互 → 错因反馈 → 生成网页”的顺序继续，先不要写代码。

---

第 3 步完成后，可以接着使用“教学设计闸门”的通用提示词，把“学”和“补”两张清单一起贴进去，让 AI 按教学设计生成网页。
