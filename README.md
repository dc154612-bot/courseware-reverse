# 课件逆向学习

看到别人做得好的互动课件，想学它的做法，再做一个属于自己的？这个工具帮你把“照着抄”变成“看懂了再做”。

你给它一个好课件，它会告诉你：

- 这个课件是怎么设计的，好在哪里
- 从教学上看，它还缺什么
- 你可以学什么、改什么、补什么，做出比原作更适合自己课堂的版本

它学的是设计思路，不复制别人的代码、图片和文字。这样做出来的作品是你自己的，也不会有侵权问题。

---

## 一、能拆哪些课件

| 类型 | 你提供什么 |
| --- | --- |
| 网页课件、多页教学网站 | 网址 |
| H5（手机上打开的课件） | 网址 |
| 教学游戏 | 网址或录屏；至少玩一局，包括一次失败 |
| PPT、PDF 课件 | 文件（.pptx 或 .pdf；其他格式先另存为这两种） |
| 希沃白板课件 | 用希沃导出的图片或 PDF，加一段放映录屏 |
| 小程序、App | 手机录屏或截图 |
| 短视频里看到的课件 | 录屏 |

只有截图也可以：按使用顺序截 4～8 张，最好包括：开头、主要操作、做对和做错时的画面、结尾。

截图和录屏里不要有学生的姓名、照片、成绩。

## 二、三种用法，选一种

### 用法 1：WorkBuddy（功能最全，推荐）

适合：能在电脑上使用 WorkBuddy 的老师。可以直接分析录屏视频。

第一次使用：

1. 解压收到的压缩包，得到 `courseware-reverse` 文件夹。
2. 在 WorkBuddy 里按添加 Skill 的方式，把整个文件夹导入。
3. 如果同时收到了“教学设计闸门”（teaching-design-gate），也一起导入。拆解完可以直接接着生成自己的课件。

以后每次使用，直接对它说，例如：

> 这个课件做得很好，我想学习它的设计，再做一个自己的。网址是……

> 这是我在抖音上录的课件视频（附上视频文件），帮我拆解一下第一个课件。

它会自动处理视频，你不需要自己运行任何命令。

### 用法 2：豆包

适合：手机或电脑上用豆包的老师。豆包能看懂图片内容。

1. 打开 `assets/portable-prompt.md`，复制分隔线之间的整段文字。
2. 填好【】里的内容，尤其是“我觉得好的地方”和“交互描述”。
3. 把截图按顺序上传，连同文字一起发送。

### 用法 3：DeepSeek

步骤和豆包一样。区别是：DeepSeek 上传图片时，主要识别图里的文字，看不太懂画面。所以“交互描述”要写得详细一些，比如：

> 1. 打开后是一条 3D 长廊，顶部一排字“金石土革丝木匏竹”。
> 2. 点“土”，画面走到土类展区，弹出一张介绍卡片。
> 3. 卡片里有一个试听按钮，点了会播放埙的声音。

## 三、你会得到什么

AI 会分三步回答：

1. 拆解：从八个方面分析原作，比如开场怎么抓人、导航怎么设计、学生主要做什么操作、做错了有什么反馈。每一项都会说明“看到了什么”和“为什么这样设计”。
2. 教学诊断：检查原作能不能让学生真正学到东西。最常见的发现是：原作做得好看，但只能看、不能练，或者学生做错了不知道错在哪。
3. 再创新方案，分三张清单：
   - 学：可以直接用到你的课上的设计
   - 改：要换成你自己的内容和外观的部分
   - 补：原作缺的教学环节，比如一个检验学习效果的小任务

最后它会问你：要用在哪个年级、哪个知识点、学生常错在哪里。回答后，它会帮你设计并生成自己的课件网页。

## 四、用得更好的小技巧

- 一次只拆一个作品。录屏里有好几个课件时，告诉它重点拆哪一个。
- 尽量提供完整的使用过程。只给首页截图，AI 看不到真正的核心操作。
- 说出你觉得好在哪里。“我喜欢它能像逛展馆一样走进去”比“做得好”有用得多。
- 原作的知识内容也要自己核对一遍。好看的课件也可能有错。

---

## 五、请遵守的规则

- 只学设计思路。不复制原作的代码、图片、音频、视频和大段文字。
- 不做“换个名字的原作”。外观、配色、素材都要自己重新设计。
- 看到作者署名、版权声明或防复制标记，说明作者在保护作品，请尊重，不要想办法去掉。
- 不破解需要登录或付费才能看的内容。

## 六、常见问题

问：需要 REA 之类的逆向软件吗？
答：不需要。REA 是用来拆解电脑程序代码的。网页课件本来就公开可见，录屏和截图更是只能看设计，这个工具学的也正是设计。

问：WorkBuddy 提示缺少组件、需要安装怎么办？
答：不同类型的课件要用到不同的组件，按提示安装即可。可以让 WorkBuddy 帮你运行，也可以自己在命令行里运行：

| 课件类型 | 需要安装 |
| --- | --- |
| 录屏 | `pip install imageio-ffmpeg pillow`（苹果电脑一般自带，可以不装） |
| 网页、H5、教学游戏 | `pip install playwright`；电脑上没有 Chrome 时，再运行 `playwright install chromium` |
| PDF | `pip install pymupdf pillow` |
| PPT | 不用装 |

实在装不上，就改用截图，照样能拆。

问：网页采集会不会给网站添麻烦？
答：脚本遵守网站的 robots.txt 规则，默认最多看 5 个页面，每页之间停顿 1 秒，不登录、不填表、不点按钮，和一个人正常浏览差不多。

问：拆完以后怎么做出自己的课件？
答：在 WorkBuddy 里，它会接着用“教学设计闸门”带你完成。用豆包或 DeepSeek 时，把“学”和“补”两张清单，一起贴进“教学设计闸门”的通用提示词里继续。
