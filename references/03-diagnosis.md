# 闸门诊断与再创新

## 诊断表

完整标准见 teaching-design-gate 技能的参考文件：01～04 是四道闸门，05 是视觉方向。逐项判断“有 / 部分 / 没有”，并写出依据。

| 检查项 | 要回答的问题 |
| --- | --- |
| 教学对齐 | 能看出它要学生学会什么吗？有学习证据吗（学生做了什么能证明学会）？ |
| 交互匹配 | 核心操作是在练这个知识，还是只是在看、在点？ |
| 脱壳测试 | 去掉 3D、动画、积分和音效后，学生还在练这个知识吗？留下的动效是在表达知识，还是在抢注意力？ |
| 错因反馈 | 做错时，有没有说清错在哪、下一步怎么做？ |
| 验收 | 学科内容是否准确？能否离线、投影、触屏使用？做题时要看的对象有没有被面板挡住、有没有高亮？ |

常见结论：做得好看的作品，大多强在“交互匹配”的前半段（让人愿意操作），弱在“学习证据”和“错因反馈”。这正是再创新的空间。原作的内容量和真实参数往往比不过，再创新要赢在学习闭环上。

也要核对原作的知识内容。如果发现错误，单独列出来，提醒老师不要照搬。

## 再创新：学 / 改 / 补 + 视觉方向

```
【学】直接迁移的机制（2～3 条，交互和视觉都算）
  例：顶部分类导航可直达；讲解面板浮在全屏场景上
【改】要换掉的部分
  内容：换成老师自己的知识点和题目
  外观：不沿用原作的配色、字体和素材，按下面的视觉方向重新定
  技术：按老师的条件调整（如改成单文件离线）
【补】原作缺的闸门（1～2 条，挑最重要的）
  例：加一个“听音找展区”任务，选错时说明差在发声方式还是余音长短
【视觉方向】和学、补一起交给生成步骤
  世界：这节课的知识发生在哪里（例：纸盒工坊、豌豆田、配电盘）
  材质：从这个世界里取 2～3 种（例：牛皮纸、折痕虚线、裁纸垫）
  配色：一个主色加一个强调色，强调色只标要学生注意的地方
  字体：标题、正文、数字各一种，只用电脑自带字体，离线也能显示
  动效：只让表达知识的东西动
  开场：封面一句提问加一个按钮
```

“补”只挑一两条最重要的，优先补学习任务和错因反馈。一次补太多，作品会变复杂，老师也很难用 AI 做出来。

定视觉方向的要点：

- 世界从这节课的学科情境里找，不从原作里找。原作是展馆，老师的课未必适合展馆。
- 一次做好几个作品时，每个作品定一个世界，不要共用一套皮肤。
- 常见的“没有设计感”：三栏白卡片像后台表单；画面只占中间一格；全篇一种黑体；没有封面。

## 常见可补的机制

- 先预测再揭晓：操作前让学生表态，锁定后才能验证。
- 答错时在场景里标出：把学生选的那一项也标在图上，和正确答案对比。
- 题目不挡图：检测时高亮被问的对象，面板避开它。
- 记录与发现：结束时汇总预测对了几次、数据和结论，一键复制当作业。
- 离线单文件：断网教室、旧一体机也能用。

## 简版闸门（没有安装 teaching-design-gate 时使用）

老师确认要做的课后，按顺序完成：

1. 对齐卡：关键问题、理解目标、常见误区、学生操作、学习证据。学习证据不能是“看完了”或“通关了”。
2. 核心交互：学生操作什么 → 界面怎么变 → 学到什么；做脱壳测试，不通过就重新设计。优先“先预测再验证”。
3. 错因反馈：每个误区写出错误答案、背后的想法、反馈文字、下一步。
4. 生成要求：单个 HTML 文件、不依赖外网、只做一个核心交互、有重置按钮、投影大字号、完整输出代码；按视觉方向做全屏场景和开场封面，系统设置了“减少动态效果”时停掉动画。空间类知识改走 `04-build-3d.md` 的 3D 骨架。
5. 上课前人工核对：知识内容、答案、隐私。

## 做完对照自查

生成之后，把自己的版本和原作在同一尺寸下截图，并排看，逐项回答：

- 教学：先预测了吗？答错时说清错因了吗？有学习证据吗？
- 视觉：第一眼像在一个“世界”里，还是像后台表单？字体有层次吗？有封面吗？动的东西在表达知识吗？
- 验收：投影大字号、窄屏、断网都能用吗？

哪一项差得多，就回到对应步骤重做。视觉上的差距最容易被忽略，先看这一项。
