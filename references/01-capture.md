# 采集材料

目标是看全原作的“完整一次使用过程”：从打开、操作、得到反馈，到结束。只看首页就拆解，最容易漏掉真正的核心交互。

## 录屏视频

```bash
python3 scripts/extract_frames.py <视频路径> --every 3
```

- 默认每 3 秒抽一帧，每 12 帧拼成一张总览图，输出到视频旁边的 `<视频名>_frames/` 文件夹。
- 先看总览图，找到每个作品的起止时间和关键操作；再对关键时刻用 `--start 秒 --end 秒 --every 0.5` 加密抽帧。
- 手机录屏里，课件通常只占画面中间一条，四周是 App 界面。看不清文字时，用 `--crop 上,下` 裁掉上下比例，例如 `--crop 0.27,0.43` 只保留 27%～43% 高度的区域。
- 脚本依次尝试 ffmpeg、Python 包 imageio-ffmpeg、macOS 自带视频接口。都不可用时，按提示安装其一，或请老师手动截图。

短视频里的课件常被剪辑和配音。注意区分：哪些是课件本身的交互，哪些只是视频剪辑效果或博主讲解。

## 网页链接（单页、多页网站、H5）

先用脚本把能看到的部分一次采集下来：

```bash
python3 scripts/capture_web.py <网址>                 # 电脑视角，默认最多 5 个同站页面
python3 scripts/capture_web.py <网址> --mobile        # 手机视角，H5 课件用这个
python3 scripts/capture_web.py <网址> --max-pages 15  # 多页网站，走更多页面
```

输出到 `web_capture/`：每页的首屏和整页截图、页面文字，以及 `report.md`。报告会列出标题结构、所有可操作控件、技术线索（是否 3D、用了哪些库、有没有音视频），并标出作者署名和隐形水印。

脚本只“打开页面看”，不点按钮。所以读完报告后，还要在浏览器里按“可操作控件”清单逐个试一遍，补全交互过程。单页应用（一个网址里切换很多画面）尤其要这样做。

脚本遵守网站的 robots.txt，不登录、不填表。需要安装 Playwright（`pip install playwright`）；装不上时，直接用浏览器手动走一遍，按下面顺序记录：

1. 首屏：标题、一句话说明、第一个按钮叫什么
2. 导航：有几层（章节、视角、页码），各叫什么
3. 走一遍主流程：每一步出现什么、点了以后画面怎么变
4. 所有控件：滑块、按钮、开关、输入框，各控制什么
5. 反馈：做对、做错、没操作时分别出现什么
6. 收尾：有没有总结、测验、成绩或给老师的数据
7. 技术形态：是否需要联网、是否有 3D（WebGL 画布）、手机上能否使用

读页面文字时优先用提取文本的方式，比截图更准确。不需要也不应该去读压缩过的源代码：设计都能从页面上看到。

## PPT / PDF 课件

```bash
python3 scripts/extract_slides.py 课件.pptx
python3 scripts/extract_slides.py 课件.pdf     # 需要 pip install pymupdf
```

- PPTX：提取每页文字、备注、图片和音视频，并统计动画、触发器、页内跳转。有触发器或跳转，说明它不是一页页往下翻的，而是“点哪里跳到哪”的互动课件，要画出跳转关系。
- PDF：导出每页图片和文字，并拼成总览图。
- PPTX 不渲染画面。想看版面时，请老师另存一份 PDF 一起处理。
- `.ppt`、`.key` 等格式：请老师在原软件里另存为 PPTX 或 PDF。
- 动画效果和触发器的实际表现，最好再配一段放映录屏。

## 希沃白板、小程序、App

这类课件的文件是平台专有格式，或者根本拿不到文件，只能靠录屏和截图。

- 希沃白板：用希沃自带的导出功能导出图片或 PDF，配合放映状态下的录屏。不要尝试解包 `.enbx` 文件。
- 小程序、App：手机录屏或截图，按录屏的方法处理。注意录屏里不要出现学生信息和登录信息。
- 这类作品常依赖平台功能（账号、班级、数据统计、蒙层、克隆）。拆解时把“平台提供的”和“作者自己设计的”分开写，只学后者；前者换平台就没有了。

## 教学游戏

按网页或录屏的方法采集，并且至少完整玩一局，包括：

- 一次成功，一次失败（故意做错，看失败时系统怎么反应）
- 第一关和后面某一关（看难度怎么递进）
- 结算画面（看给的是分数、星级，还是对学习的反馈）

## 截图

- 请老师按使用顺序编号上传，最好覆盖首屏、主要操作、反馈、结尾。
- 截图看不出动态效果。对关键交互，请老师用一句话描述“点了什么，画面怎么变”。
